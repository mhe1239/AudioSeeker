# 재생 서비스 위치 저장 실제 기기 검증

## 목표

AudioSeeker가 화면을 닫은 뒤 백그라운드 재생, 최근 앱에서 작업 제거, 서비스 재생성 뒤에도 마지막 곡과 위치를 기대대로 복원하는지 실제 기기에서 확인한다.

## 확인 항목

- 곡 중간 재생 후 앱 화면을 닫고 다시 열었을 때 위치가 복원되는지 확인한다.
- 백그라운드 재생 중 최근 앱에서 작업을 제거한 뒤 서비스가 유지되거나 종료될 때 저장 위치가 유효한지 확인한다.
- 재생 종료 직전 위치가 다음 실행에서 다시 재생되지 않는지 확인한다.
- 잠금 상태, 알림 미디어 컨트롤, 화면 회전·분할 화면에서도 기존 제약이 회귀하지 않는지 확인한다.

## 완료 기준

- 위 항목의 기기·OS 버전·결과를 작업 보고서에 기록한다.
- 재현 가능한 실패가 있으면 최소 수정과 관련 검증을 추가한다.
