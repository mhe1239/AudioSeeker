# 재생 서비스 위치 저장 실제 기기 검증

## 목표

AudioSeeker가 화면을 닫은 뒤 백그라운드 재생, 최근 앱에서 작업 제거, 서비스 재생성 뒤에도 마지막 곡과 위치를 기대대로 복원하는지 실제 기기에서 확인한다.

## 확인 결과

- [x] Galaxy S23+ (`SM-S916N`, Android 16)에서 재생 중 화면을 떠났다가 다시 열어도 위치가 연속됐다.
- [x] 최근 앱에서 AudioSeeker 카드를 제거한 뒤에도 서비스가 재생을 유지했고, 다시 연 화면에서 위치가 이어졌다.
- [x] 프로세스를 강제 종료해 서비스를 재생성한 뒤 재생 바로가기로 시작했을 때 저장 위치에서 재개됐다.
- [x] 실제 두 앱이 동시에 보이는 분할 화면에서 UI 위치가 즉시 이어지는지 확인했다. 2026-10-27 SM-S916N에서 AudioSeeker 상단·FocusClock 하단 분할 상태의 저장 위치와 Media3 위치가 모두 `541.950초`로 일치했다.
- [ ] 재생 종료 직전 위치가 다음 실행에서 다시 재생되지 않는지 확인한다.
- [ ] 잠금 상태·알림 미디어 컨트롤·화면 회전에서 기존 제약이 회귀하지 않는지 확인한다.

## 추가 검증 기록 (2026-10-27, SM-S916N)

- [x] 위치 정확도 수정 APK를 기존 데이터 유지 설치한 뒤, 저장돼 있던 `396.174초` 위치에서 같은 강의가 복원됐다.
- [x] 홈으로 이동할 때 저장 위치가 `398.479초`로 즉시 갱신됐고, 1.2초 뒤 백그라운드 미디어 세션은 `399.804초`를 재생 중이었다. 앱을 다시 열어도 재생은 연속됐으며 수 초 단위 되감김은 나타나지 않았다.
- [x] 실제 삼성 분할 화면 UI에서 재현했다. AudioSeeker가 포커스를 잃은 상태에서도 마지막 재생 위치가 즉시 저장됐다.
- [x] Galaxy S23+에서 재생 중 홈 화면으로 나갔다가 런처와 재생 바로가기로 재진입해도 단일 최상위 활동으로 전달되고 재생 세션·위치가 계속 진행하는지 확인했다. (2026-10-30)
- [ ] 장시간 비활성으로 재생 서비스가 종료된 뒤에도 마지막 항목이 일시정지 상태로 표시되고 재생 버튼에서 저장 위치로 이어지는지 확인한다.
- [ ] 분할 화면 비율 변경에서도 `MainActivity`가 재생성되지 않고 UI가 저장 위치로 되돌지 않으며 서비스의 현재 위치를 유지하는지 확인한다.
