# 파일 경계 무음 줄이기 실제 기기 검증

## 목적

옵션을 켰을 때 파일 전환의 시작·끝 무음만 줄고, 강의 본문 중 침묵은 그대로 남는지 실제 기기에서 확인한다.

## 확인 항목

- 설정 기본값이 꺼짐이며, 껐을 때는 원본 파일의 시작·끝 구간이 그대로 재생되는지 확인한다.
- 시작 또는 끝에 250ms 이상 무음이 있는 두 파일을 연속 재생해, 각 경계에서 최대 1.5초만 줄어드는지 확인한다.
- 강의 중간에 긴 침묵이 있는 파일을 재생해 내부 침묵이 삭제되거나 빨라지지 않는지 확인한다.
- MP3, M4A 등 지원 형식에서 앞·뒤 경계 분석이 재생 시작을 과도하게 늦추지 않는지 확인한다.
- 디코더가 지원하지 않는 파일 또는 분석 실패 파일이 오류 없이 원래 구간으로 재생되는지 확인한다.
- 셔플, 반복, 백그라운드 재생, 다음/이전 곡 조작 중에도 큐와 재생 위치가 비정상적으로 바뀌지 않는지 확인한다.

## 실기기 진행 결과 (2026-10-27, SM-S916N)

- [x] 기본값이 꺼짐인 것을 확인했다. 옵션을 끈 상태에서 `AudioSeekerBoundaryCheck.m4a`는 원본 7초로 표시·재생됐다.
- [x] 설정을 켜고 앱을 재시작해도 선택값이 유지되는 것을 확인했다.
- [x] 제어용 MP3·M4A 파일에서 파일 경계 클리핑이 적용됐다. M4A는 설정을 켰을 때 재생 시간이 4초 단위로 표시됐고, MP3 미디어 세션의 재생 버퍼는 약 4.512초였다.
- [x] 제어용 M4A 원본은 앞 1초 무음·중간 2초 무음·끝 2초 무음으로 구성됐다. 적용 후 약 4.5초가 남아 중간 2초 무음이 제거되지 않았음을 확인했다. 경계 무음만 줄였다면 예상값은 4.5초이고, 중간 무음까지 제거했다면 약 2.5초가 되어야 한다.
- [x] MP3에서 다음 곡 조작 뒤에도 미디어 세션이 `PLAYING` 상태를 유지했으며, 앱 예외나 MediaCodec 오류는 확인되지 않았다.
- [ ] 디코더가 지원하지 않는 파일 또는 분석 실패 파일의 원본 재생 폴백은 아직 확인하지 않았다.
- [ ] 셔플·반복·백그라운드 조합의 큐·재생 위치 회귀는 아직 확인하지 않았다.
