# 작업 보고서: 문서 중심 아키텍처 도입

- 작성일: 2026-10-15
- 상태: 완료
- 관련 요구사항: [`AGENTS.md`](../../AGENTS.md), [`REQUIREMENTS.md`](../../REQUIREMENTS.md)

## 변경 내용

- Austin Docs Architecture의 핵심 진입 구조를 AudioSeeker에 맞게 도입했다.
- 저장소 규약, 폴더 구조, 기술 사양, 제품 계획, TODO·작업 보고서 템플릿을 추가했다.
- REA의 활성 스킬·MCP·증거 규칙이 프로젝트 문서 규약보다 우선함을 `AGENTS.md`와 기술 사양에 명시했다.
- 기존 구현과 어긋난 `REQUIREMENTS.md`의 테마·재생 속도·루틴 재생 항목을 현재 제공 범위에 맞게 정리했다.
- 기존 복원·검증 이력인 `docs/RECONSTRUCTION.md`는 변경하지 않고, 필요할 때만 참조하는 기록으로 분리했다.

## 검증

- 새 문서의 경로와 내부 링크를 점검했다.
- 이번 변경에는 Kotlin·리소스·Gradle 변경이 없으므로 Android 빌드는 실행하지 않았다.

## 판단과 제약

- REA는 런타임·바이너리 분석에 필요한 경우 우선 적용한다. 일반적인 소스 구현과 문서 작업에는 불필요한 분석을 강제하지 않는다.
- REA의 전역 설치와 MCP 등록은 이번 변경 범위에 포함하지 않는다.
