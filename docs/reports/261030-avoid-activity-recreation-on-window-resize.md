# 작업 보고서: 창 크기 변경 시 활동 재생성 방지

- 작성일: 2026-10-30
- 상태: 완료
- 관련 요구사항: `REQUIREMENTS.md`의 분할 화면 및 이어 듣기 요구사항

## 변경 내용

- `MainActivity`가 방향·화면 크기·최소 화면 크기·화면 레이아웃 구성 변경을 직접 처리하도록 매니페스트에 선언했다.
- 분할 화면 진입 또는 비율 변경 시 기존 활동을 파괴하고 다시 만드는 대신 Compose가 새 크기로 리컴포지션하도록 했다.
- 재생 중 UI가 저장된 위치로 잠시 되돌아가는지 확인하는 실제 기기 TODO를 활동 재생성 확인까지 확장했다.

## 검증

- `./gradlew.bat assembleDebug` 성공: 매니페스트 병합과 디버그 APK 생성을 확인했다.
- Galaxy S23+ (`SM-S916N`)에 기존 데이터 유지 방식으로 디버그 APK를 설치했다.

## 판단과 제약

- 이 선언은 크기 기반 구성 변경만 처리한다. 시스템 테마, 언어, 프로세스 종료처럼 다른 변경 원인은 Android 기본 재생성·상태 복원 경로를 계속 사용한다.
- Compose UI는 변경된 `LocalConfiguration` 값으로 리컴포지션하지만, 실제 Samsung 분할 화면에서 재생 중 연속성은 추가 기기 검증이 필요하다.
