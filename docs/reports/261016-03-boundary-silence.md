# 파일 경계 무음 줄이기 구현 기록

## 결정

곡 전환 시 무음 줄이기는 기본으로 끈다. 사용자가 켠 경우에도 파일 중간의 무음은 분석하거나 제거하지 않고, 파일 시작과 끝의 연속 무음만 최대 1.5초 줄인다.

## 구현

- `BoundarySilenceAnalyzer`가 로컬 파일의 처음 3초와 마지막 5초만 PCM으로 디코딩한다.
- 250ms보다 짧은 무음은 유지한다.
- 감지된 시작·끝 무음은 Media3 미디어 항목의 재생 구간으로 적용한다.
- 현재 선택한 곡은 재생 전 분석하고, 정상 순서의 다음 곡은 백그라운드에서 미리 분석한다.
- 디코더·분석 단계가 실패하면 빈 클리핑 결과를 사용하므로 원본 파일을 그대로 재생한다.

Media3의 전체 무음 건너뛰기 기능은 파일 내부의 강의 침묵까지 바꿀 수 있어 사용하지 않았다.

## REA 관련 기록

기존 Samsung Music REA 기록은 서비스 기반 재생·이어 듣기 구조를 확인한
`261016-rea-samsung-music-playback-resume.md`에 남아 있다. 이번 기능은 해당 구조를 참고하되,
삼성 앱의 무음 처리 동작을 재현했다고 주장하지 않는다. 현재 작업 세션에서는 REA MCP/JADX 제공자가
노출되지 않아 새 정적 증거를 수집하지 못했다. 실제 기기 재생 결과는 별도 검증 TODO로 남긴다.
