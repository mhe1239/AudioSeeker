# 작업 보고서: 자동 끄기 타이머

- 작성일: 2026-10-16
- 상태: 완료
- 관련 요구사항: `REQUIREMENTS.md`의 재생과 탐색

## 변경 내용

- 설정에 기본값이 꺼진 자동 끄기 타이머를 추가했다.
- 15분, 30분, 현재 곡 끝, 사용자 지정 1~720분과 사용 안 함을 지원한다.
- 만료 시각과 현재 곡 ID를 저장하고 `PlaybackService`가 타이머를 복원·만료 처리해, 화면이 닫혀도 재생을 일시정지한다.
- 현재 곡 끝 옵션은 자동 전환과 반복 전환에서 지정한 곡이 끝나면 재생을 멈춘다.

## 검증

- `:app:assembleDebug` 빌드 성공.
- 실제 기기·백그라운드·반복 재생 검증은 TODO로 남겼다.

## REA 관찰과 제약

- 관찰: REA 6.5.0의 Codex 등록은 정상이나, 현재 세션에는 REA MCP 도구가 연결되지 않았고 Android 정적 분석용 JADX 제공자도 구성되지 않았다.
- 관찰: 기존 Samsung Music 정적 분석 기록은 서비스 중심 재생 관리 근거를 남기지만, 자동 끄기 타이머의 내부 동작을 확정하는 증거는 아니다.
- 설계: AudioSeeker의 타이머는 화면이 아닌 `PlaybackService`가 관리한다. 이는 기존 Samsung Music REA 기록의 서비스 중심 재생 구조를 참고한 설계이며, Samsung Music의 타이머 동작을 재현했다는 주장은 아니다.
