# 작업 보고서: 재진입 시 서비스 위치 우선 표시

- 작성일: 2026-10-30
- 상태: 완료
- 관련 요구사항: `REQUIREMENTS.md`의 이어 듣기 요구사항

## 변경 내용

- 미디어 컨트롤러가 연결된 뒤 준비 상태가 아닐 때 저장 위치를 임시로 표시하던 보정 로직을 제거했다.
- 앱 재진입을 포함해 컨트롤러 동기화가 발생하면 `PlayerViewModel`은 서비스가 보고한 실제 위치를 항상 UI에 반영한다.
- 홈 화면에서 재진입하는 흐름을 실제 기기 검증 TODO에 추가했다.

## 검증

- `./gradlew.bat assembleDebug` 성공: 변경된 재생 상태 동기화 코드의 컴파일과 디버그 APK 생성을 확인했다.
- Galaxy S23+ (`SM-S916N`)에 기존 데이터 유지 방식으로 디버그 APK를 설치했다.

## 판단과 제약

- 저장 위치는 마지막 재생 항목을 새로 시작하거나 서비스가 재생성될 때만 탐색 시작점으로 사용한다.
- 컨트롤러가 아직 연결되기 전의 초기 화면 상태는 저장값을 보유할 수 있지만, 연결 완료 후 저장값으로 다시 덮어쓰지 않는다.
