# 작업 보고서: 재생 중 위치 복원 방지

- 작성일: 2026-10-30
- 상태: 완료
- 관련 요구사항: `REQUIREMENTS.md`의 이어 듣기와 분할 화면 요구사항

## 변경 내용

- 재생 상태 동기화에서 Media3가 준비 중이더라도 실제 재생 중이면 저장된 위치를 유지하지 않고, 재생 서비스가 보고한 현재 위치를 사용하도록 했다.
- 앱 재진입·화면 재생성·분할 화면 비율 변경 시 재생 위치가 과거 저장값으로 보이거나 되돌아가는 것을 방지하는 규칙을 기술 사양에 기록했다.
- 실제 기기 검증 TODO에 해당 회귀 확인 항목을 추가했다.

## 검증

- `./gradlew.bat assembleDebug`를 실행해 변경된 `PlayerViewModel.kt`의 Kotlin 컴파일이 오류 없이 완료되고 디버그 APK가 갱신된 것을 확인했다.
- Media3 클립 위치 설정 API의 기존 deprecation 경고 2개가 출력됐으며, 이번 변경에서 새로 발생한 경고는 아니다.

## 판단과 제약

- 재생 중이 아닐 때는 서비스 연결 및 준비 상태에서 기존 저장 위치를 계속 표시해 초기 UI의 불필요한 0초 점프를 피한다.
- 재생 중 위치 연속성은 실제 기기의 앱 재진입과 분할 화면 비율 변경에서 추가로 확인해야 한다.
