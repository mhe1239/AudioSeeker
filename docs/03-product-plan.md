# 제품 계획

## 제품 목표

AudioSeeker는 기기 안의 오디오 파일을 빠르게 찾고, 폴더·검색 결과 단위로 자연스럽게 재생하는 Android 로컬 음악 플레이어다. 외부 스트리밍·계정·클라우드 동기화는 제품 범위가 아니다.

## 현재 제공 범위

- MediaStore 기반 자동 스캔, 검색, 정렬과 폴더 분류
- 폴더와 검색 결과를 재생 큐로 사용하는 재생·탐색·이전/다음 곡 제어
- 현재 큐 범위의 셔플과 반복(한 번, 전체 반복, 한 곡 반복)
- 0.5~2.0배 재생 속도 설정과 저장
- 시스템/청록 다크/표준 다크를 포함한 테마 선택
- 재생 동작 앱 바로가기를 통한 루틴 연동 진입점
- 잠금 상태, 작은 창 높이, 접근성에 맞춘 재생 화면 제약

## 제품 원칙

- 라이브러리와 재생은 오프라인·로컬 파일 우선으로 설계한다.
- 현재 사용자가 보고 선택한 범위가 곧 재생 큐의 범위가 된다.
- 파일 삭제처럼 되돌리기 어려운 동작은 Android 권한 흐름과 확인 단계를 존중한다.
- 시스템 기능(알림, 잠금 화면, 루틴)은 표준 Android 계약을 우선하며 제조사별 노출 여부를 앱 기능 보장으로 약속하지 않는다.

기능을 완료하면 이 문서의 현재 제공 범위와 다음 후보를 갱신하고, 판단 근거는 `docs/reports/`에 남긴다. 요구사항의 확정 문구는 `REQUIREMENTS.md`와 충돌하지 않도록 함께 정리한다.
